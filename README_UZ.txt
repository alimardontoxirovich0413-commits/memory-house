MEMORY HOUSE — DASTLABKI ISHLAYDIGAN PROTOTIP

Bu loyiha virtual uy-muzeyning dastlabki veb prototipidir:
- oldindan berilgan muzeylar va foydalanuvchi yaratadigan muzey;
- telefon galereyasidan bir nechta rasm tanlash;
- rasmlarni IndexedDB ichida saqlash;
- muzey nomlari va sozlamalarini localStorage ichida saqlash;
- oddiy 3D xona, birinchi shaxs ko‘rinishida yurish va atrofga qarash;
- uch xil xona uslubi.

MUHIM CHEKLOVLAR:
- Bu hali Google Play'ga tayyor APK emas.
- Boshqa haqiqiy foydalanuvchilar bilan onlayn ko‘rish/multiplayer yo‘q.
- Virtual odamlar (AI/NPC) hali yo‘q.
- Administrator paneli va server hali yo‘q.
- Three.js kutubxonasi CDN orqali yuklanadi, shu sababli birinchi ochishda internet kerak.
- Bu prototipdagi saqlash qurilmaga bog‘liq; brauzer ma’lumotlari o‘chirilsa, rasmlar yo‘qolishi mumkin.
- Google Play'ga chiqarishdan oldin xavfsizlik, maxfiylik siyosati, test va Android paketlash kerak.

TELEFONDA SINASH:
1. ZIP arxivni brauzerda ishlaydigan statik sayt xizmati yoki GitHub repository'ga joylashtirish kerak.
2. HTTPS orqali oching.
3. Chrome'da ochib, galereyadan rasm tanlang.
4. Pastdagi yo‘nalish tugmalari bilan yuring; barmoq bilan sahnani surib atrofga qarang.

Keyingi ishlab chiqish bosqichlari:
1. Kodni GitHub repository'ga joylash.
2. HTTPS hosting orqali prototipni ishga tushirish.
3. Telefonlarda test qilish.
4. Xonalar, rasm joylashtirishni tahrirlash va UI'ni takomillashtirish.
5. Onlayn muzeylar, login, ruxsatlar va administrator paneli.
6. Android paketlash va Google Play sinovi.
